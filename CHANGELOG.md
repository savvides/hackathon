# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-03-28

### Added

- 4 operational templates: event design document, student guide, 26-point binary evaluation rubric, mentor briefing
- 50-problem curated bank organized in 3 parts: 17 education-health intersection, 16 education-only, 17 health-only
- Each problem follows 7-component structure: problem statement, affected stakeholders, current inadequate solutions, regional context, global context, ethical considerations (PI framework), prototype scope
- 3 high-difficulty differentiation problems flagged for top teams
- Post-hackathon entrepreneurship resource guide (ASU/Arizona ecosystem as worked example)
- Principled Innovation (PI) framework integration as mandatory judging criterion (5 of 26 points)
- Station-based mentoring model with themed stations and roaming mentors
- Pre-assigned team formation methodology with stratified random assignment
