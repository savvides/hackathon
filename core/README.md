# Core Toolkit

This directory contains the agnostic, reusable framework for running an ethics-integrated hackathon. These files represent the "engine" of the event and are designed to be transferable to any institution with minimal changes.

## Components

### Event Logic (`core/event-logic/`)
- **`design-document.md`**: The organizer's master blueprint. Covers schedule, registration, team formation rules, and the judging process. This is your starting point.

### Templates (`core/templates/`)
- **`student-guide.md`**: The participant-facing handbook. Includes the schedule, mentor station directory, and event rules.
- **`evaluation-criteria.md`**: A 26-point binary scoring rubric (Yes/No) covering eight dimensions, including a mandatory ethical reasoning component.
- **`mentor-briefing.md`**: A one-page context builder for mentors, designed to be read in 5 minutes.

## Adaptation Guide

When preparing for your event, focus on these areas:
- **Contacts**: Replace placeholders for Event Leads, Campus Security, and communication channels (Slack/Discord).
- **Mentors**: Populate the `student-guide.md` mentor roster with your specific experts.
- **Ethics**: While we use the "Principled Innovation" framework, you can substitute any responsible innovation or design ethics model.
