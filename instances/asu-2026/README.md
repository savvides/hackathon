# ASU 2026 Pilot (Worked Example)

This directory contains the specific data and challenges used during the 2026 pilot at Arizona State University. It serves as a comprehensive "worked example" of how to apply the core toolkit to a specific region and set of problems.

## Contents

- **`problem-bank.md`**: 50 challenge problems focused on Arizona's healthcare and education landscape (e.g., heat vulnerability, tribal health, workforce shortages).
- **`local-resources.md`**: A guide to the ASU and Phoenix-area entrepreneurship ecosystem, showing participants "what's next" after the hackathon.

## Using this Example

If you are running a hackathon in a different region:
1. **Swap the Problems**: Replace Arizona-specific data (like nursing shortage projections) with your own regional challenges.
2. **Re-map the Ecosystem**: Replace the ASU resource list with your own institution's accelerators, maker spaces, and funding opportunities.
3. **Analyze the Format**: Notice how each problem is grounded in "Global Context"—the challenges are universal, even if the data points are local.
